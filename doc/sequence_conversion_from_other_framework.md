# Sequence Conversion from Other Framework

SeqEyes reads Pulseq `.seq` files. Sequences from other frameworks can be viewed after conversion to Pulseq.

| Source / framework | Link |
|---|---|
| Siemens DSV | [mavel101/dsv2pulseq](https://github.com/mavel101/dsv2pulseq) |
| gammaSTAR | [gammaSTAR](https://gammastar.mevis.fraunhofer.de/#/dashboard) |
| Hawk / SpinBench-style descriptions | [usc-mrel/hawk_to_pypulseq](https://github.com/usc-mrel/hawk_to_pypulseq) |
